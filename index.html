Data format and validation

JSON schema: {"players":[{"id":"p1","name":"Player One"}],"stints":[{"playerId":"p1","clubId":"CLUB","clubName":"Team Name","start":"2024-04-01","end":"2024-09-30","source":"source citation"}]}

Only overlapping inclusive date intervals on the same club produce an edge. All stints must have a source. The importer checks IDs, dates, source fields and duplicate player IDs; it cannot independently authenticate a source citation. A game appearance should be represented as a one-day stint unless roster tenure is independently established. The fictional sample is for interface testing only and must never be presented as MLB history.
